# Triage labels

Use these exact strings for a ticket's triage status. They map directly to the canonical skill roles.

| Label             | Meaning                                             |
| ----------------- | --------------------------------------------------- |
| `needs-triage`    | Maintainer needs to evaluate the issue              |
| `needs-info`      | Waiting on the reporter for information             |
| `ready-for-agent` | Fully specified for autonomous agent implementation |
| `ready-for-human` | Requires human implementation                       |
| `wontfix`         | Will not be actioned                                |

Wayfinding uses the separate `claimed` / `resolved` work states described in [issue-tracker.md](issue-tracker.md#wayfinding).
